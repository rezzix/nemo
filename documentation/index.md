# Nemo knowledge base

An [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) (OKF v0.1) bundle documenting Nemo — a multi-company project-management system combining task tracking, time tracking, project documentation, and PMO/finance capabilities, shipped as a single Spring Boot JAR serving a REST API and a React SPA.

This bundle is split into two halves: a stable **Charter** describing what Nemo *is*, and a volatile **State** tracking where the implementation *stands*.

## Charter

The stable, foundational description of the system — vision, architecture, tech stack, per-module design, security model, API contracts, and testing strategy. Charter content changes only when the system's intent changes; it does not track progress.

→ [Charter index](/charter/index.md)

## State

The live project tracking — an advancement summary, per-module development status, per-module test plans, the current quickstart, the Postman collection, and the bundle changelog. State points back to the Charter as the plan of record; the Charter never references State.

→ [State index](/state/index.md)
