# Test plans

Per-module test coverage plans — one `module-testplan.md` per backend module group. These describe **planned** coverage: the backend currently ships no tests (`backend/src/test` has no `.java` files). The shared strategy, infrastructure, and test-data conventions they all cross-reference live in [testing strategy](/charter/testing-strategy.md); the executable API exercise collection is the [Postman collection](/state/postman-collection.md).
